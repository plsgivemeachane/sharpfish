# Piece images

The "cburnett" chess piece set by [Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett),

`scp096.png` is cropped from a screenshot of SCP-096 in *SCP – Containment Breach*
([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:SCP-096_(SCP_-_Containment_Breach).jpg),
CC BY-SA 3.0). SCP-096 itself comes from the [SCP Foundation](https://scp-wiki.wikidot.com/scp-096)
wiki (CC BY-SA 3.0).

[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

`sets.zip` archive. The author discussed these sets in
[Lichess issue #5647](https://github.com/lichess-org/lila/issues/5647).
[Lichess's asset credits](https://github.com/lichess-org/lila/blob/master/COPYING.md)
identify `public/piece/staunty` as sadsnake1's work under CC BY-NC-SA 4.0.
